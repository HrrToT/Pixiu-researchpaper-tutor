# 比较材料不足的明确表达（.399）

G1N-v7 的模型存储/显存目标原先只能使用“方法相对基线、all/exists、实验域”的推广边界，因此生成了“相对无提供数据”之类不合适的句子，独立审核正确拒绝。它需要表达的是当前所引证据是否足够，而不是编造一个实验基线或断言作者全篇遗漏。

服务器冻结的 scopeExpressionContractVersion=5 新增 notEstablished 的一种形状：

```json
{"type":"comparison_evidence","subjects":["GOF","PGSR"],"quantity":"模型存储或显存"}
```

正文渲染为“当前引用不足以比较GOF与PGSR的模型存储或显存。”独立审核实际收到的正向命题是“当前所引证据提供了足以比较GOF与PGSR的模型存储或显存的对应数据和必要条件”。只有独立审核为不蕴涵、范围明确、不是负面结果或作者遗漏，且自己的原文前提完整绑定时，边界才可能通过。已有充分数据、理由未定、错误来源和负面断言仍失败。结构本身没有批准作用。

这个形状沿用现有 scopeExpression 两个数组和独立逐命题审核，起草、修订、恢复及压缩都接入同一版本。压缩不能更换材料不足的对象、指标或类型；旧版本1—4提示/渲染保持，旧待发身份不能切换为5。数值阈值锚定仍启用。

新版合并说明1813字节，旧事实边界说明1824字节。保存G1N-v6输入的零模型前瞻回放：新三组唯一修订输入23904、23861、19032字节，原24KB上限保持。回放仅说明输入可准备，不能证明实际模型会正确选择结构或完成整题。旧历史payload不修改。

首次196文件回归有8个失败，均为旧服务器版本4预期；原证据保留。测试更新为服务器5、旧值/非法类型仍不可改写，并保留未来版本6检查。最初新增压缩测试误把位置参数当成关键字读取，修正测试后相关60项通过。最终冻结关联回归结果单独归档。

未计真实内容通过或独立积分；表示方式缺漏、完整比较和原DR0—DR5其他验收仍需继续。
