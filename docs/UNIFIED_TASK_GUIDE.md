## 使用

打开 `http://localhost:5173/?unified=1`，创建并命名任务，在左侧上传或添加论文。文件上传完成后即可阅读，正文解析与索引就绪后可基于全文问答；论文概览按需生成。

任务组织论文、对话、学习活动、笔记和成果。对话默认可使用任务中的全部材料；“这篇论文”以中栏当前论文为主，显式选择材料时遵守本轮选择。继续原学习活动时保持该活动的论文，切换中栏不会把学习对象换掉。

可自然提问，也可在输入框键入 `/` 选择功能、键入 `@` 选择材料：

| 功能 | 示例输入（文档示例，不会自动执行） |
| --- | --- |
| 精读 | `/精读 我第一次读这类论文，先帮我理解方法解决了什么问题` |
| 补课 | `/补课 我不理解透明度和透射率的区别` |
| 自测 | `/自测 检查我是否理解剪枝的重要性指标` |
| 批判 | `/批判 这篇论文的速度主张依赖哪些比较条件` |
| 比较 | `/比较 比较任务中两篇论文的表示大小和质量取舍` |
| 研究 | `/研究 整理两篇论文支持的一个可验证问题` |

简单解释直接问即可。需要组合能力时自然描述目标，例如先解释概念再比较；不需要进入独立Agent界面。研究先给计划，可调整后执行。长结果可在中栏打开，来源按需展开。

精读或自测中可以追问术语、请求提示、补课，再回到原问题作答；暂停、跳过、重答和结束由当前学习状态提供。反馈无法依据材料判断时，不应视为已掌握。

中栏支持目录和页码跳转、原文缩放、划词解释/笔记、译文及对照。无文字页仍可查看原图；当前没有OCR链路，文字工具不能从图片恢复正文。切到另一页后，前页的迟到译文只存入前页，不改变当前阅读位置。部分译文保留已完成内容；失败或中断的翻译需手动重试。

将回答收藏为笔记或保存为成果后，在左侧打开。正文默认阅读，点击编辑后修改、保存；未保存草稿可继续编辑，历史版本、来源、移动和导出按需展开。移动到缺少来源论文的任务时，会请求确认加入关联材料。Markdown导出包含当前正文和折叠来源。

宽屏可收起三栏、调宽，或专注阅读/对话；窄屏以阅读和对话切换、导航抽屉操作。请求响应未确认时先查询状态；显式继续沿用原问题与请求身份。不要连续新发相同问题来代替恢复。

## 当前验证环境

实际组合是本机Vite5173、Java8081、Compose Python8000与GROBID8070。前端默认Java地址为8081，可由`VITE_API_BASE_URL`覆盖；Java默认Python地址为`http://localhost:8000/api`，Compose内使用`PYTHON_URL`。

已有运行环境的启动命令见 [阶段0基线](STAGE0_RUNTIME_BASELINE.md#可复现启动)。该文档的验收Java库位于`backend-java/target/stage0-data`；执行`mvn clean`会删除该测试库。正式服务的默认库在`backend-java/data`，Compose使用持久化卷；不要在未备份、未核对库路径时切换数据目录。新机器的依赖与镜像准备见根README。

只读健康核对：

```powershell
Invoke-RestMethod http://localhost:8000/health
Invoke-RestMethod http://localhost:8070/api/isalive
Invoke-RestMethod http://localhost:8081/api/task-workspaces | Select-Object id,title,revision
```

需要重启Python加载源码时，先确认无运行中生成任务；重启不能当作重复模型验证。凭证从已有`.env`加载，不写入指南或验收记录。
