## 2. 开发变慢的原因及纠正

| 问题 | 接下来的纠正 |
| --- | --- |
| 局部补丁通过后才发现下一阶段破坏答案 | 同一候选从生成、审核、一次修订一直检查到发布正文与持久化 |
| 模型承担行号、指标、值和多套格式的重复填写 | 程序提供对象与证据标识，模型选择并解释；结构解析与事实判断分开 |
| 新手化改写改变论文对象、维度和证据范围 | 当前新比较候选直接生成读者可懂的首稿，保留事实和整答审核；改善效果须实测 |
| 总Token有剩余，修订仍装不下或来不及 | 发送前测完整路径的输入、输出预留、普通池、修订空间及时间；总量与阶段容量分开 |
| 相同问题多次付费重现，未稳定源码就跑全量 | 保存响应先回放，开发中跑相关集，稳定候选一次全量后再一次真实验证 |
| 兼容版本与文档逐轮增长 | 新开发只走一个明确入口；历史解释集中在边界，不能迁移旧未知调用或改判旧失败 |
| 环境恢复挤占功能开发 | Docker仅在装载和集成门槛介入；非环境任务继续。已知正常主机可运行的检查不反复在异常沙箱重试 |

不降低来源、数值、语义或可恢复调用要求。可容忍的表现层差异应由窄范围、可验证的解析规则处理，不能据此放行事实错误。

## 3. 接下来五个交付阶段

| 顺序 | 可审查交付 | 退出条件 |
| --- | --- | --- |
| 1 比较成果 | 当前统一输出候选、一次完整比较正文、对应证据与预算记录 | 双方相关维度、综合结论、可比条件和建议有支持；缺证据处明确，不用单格代替整答 |
| 2 实验方案 | 从研究问题到四组对照的完整可执行方案 | 共同起点、变量、训练/处理预算、指标、主效应与交互解释、操作步骤和局限成立；无虚构实验结果 |
| 3 独立能力验收 | 原D1—D6/H1—H6逐项有效证据映射，仅补未过项 | 新材料未参与调试；实际联网发现与正文获取成立；冲突、失败、预算耗尽和未知调用行为正确 |
| 4 产品闭环 | 真实生成成果经过查看、原文定位、追问、保存、编辑、找回、重开 | 正文、来源和保存版本一致；与并行交互任务接口一致，必要异常恢复可核对 |
| 5 发布 | 冻结版本、必要回归、运行说明、回退记录与PR | 所有适用硬门槛完成，内容评分满足原标准，再退出草稿；不自动合并 |

阶段3的证据盘点、阶段4的接口核对可穿插等待时间完成。比较与实验生成架构不同时大改。不能把待实现项目改写为“不适用”以结束开发。

## 4. 每个候选只走一条短反馈链

1. 定义一个用户可见的成功结果，以及这次要验证的失败机制。列出最多三个主要阻断，先修会使后续结果无效的一项。
2. 用保存材料、真实生产节点和隔离仓储重现；列出首个失真位置。确定性错误不调用付费模型重现。
3. 集中完成相互依赖的生产修改，运行相关模块及跨阶段集成。测试覆盖实际失败和边界，避免每个词形增加专用模块。
4. 核对整轮预算与容量；冻结源码，提交明确文件，运行一次完整回归。执行中不改生产源码。记录源码、执行器和结果身份。
5. 装载时检查候选版本与数据身份；按已有授权提交一次有界真实案例，保存原始输出，无自动重试。
6. 阅读完整最终正文，与来源逐项核查，再看结构和过程指标。分别报告工程、内容、产品门槛，不能相互替代。

全量之后仅文档或脱敏证据变化，无需重跑全量。生产代码变化先跑受影响集，到了新稳定候选再全量；不能把旧全量与新局部相加作为新全量。

## 5. 对反复失败设立明确决策点

- 同一根因连续两次修复未改善完整结果：停止同题付费循环，比较替代结构，选择最小可证伪方案；不再仅追加提示词。
- 格式或身份问题：优先程序约束与局部失败隔离；不让一个无效目标丢掉其余有效成果。
- 证据正确而生成持续误读：评估更明确的任务分配或有界拆分；只有对照结果表明模型能力为瓶颈时，才提出模型路由调整。
- 整轮超预算：先减少重复输入、冗余阶段及无关审核载荷。仍不可行则给出阶段测量和预算/模型取舍，不默默删研究要求。
- 检索或解析缺证：修上游材料链；不在生成提示中堆规则掩盖缺证，也不把未检出写成不存在。
- 请求终态未知：冻结原身份与预留，不重发、不换名复制。该记录不能无条件阻塞其他独立工作。

## 6. 立即执行顺序

1. 审查当前统一输出候选的源码、协议边界及受控回放证据，提交本批明确文件；不吸收并行交互任务的脏文件。
2. 在已确认可运行的正常主机环境冻结一次全量，以9559项为历史基线；处理真实失败，不能靠改断言伪造通过。
3. 源码与装载核对后，一次真实比较；重点检查完整正文、精确表格归属、磁盘存储与显存区分、首稿可读性和剩余修订容量。
4. 比较通过后进入实验方案；若失败按第5节分类决策，避免无限重跑。
5. 在等待验证时整理一张精简验收矩阵：要求、当前证据、适用版本、缺口、下一动作。历史证据只保留原适用范围。
