# 普通结论与结构化范围说明联合压缩

## 实现

当带有版本 2 范围表达式的短回答超限时，在既有一次 `synthesize_compact` 调用中同时提交普通结论和原始范围结构。所有回答点共享包含标题和提示后的展示字数预算，范围说明不再整段冻结、将压力全部转嫁给普通结论。

模型对普通点返回文字，对范围点返回结构，后者保持空 text 和 conditions。系统保留回答点顺序、kind、自身引用、义务及表格绑定，不接受模型返回这些字段。范围结构保持观察和推广命题的数量及原量词，只允许缩短字段表述。领域、主体、比较基线和标准仍是待审核声明，字段形式无法证明语义等价。

系统重新编译全部新结构，产生与新正文匹配的 unchecked 审计，再使用原有完整事实、来源、范围与最终覆盖核查。旧 AST 不会给新正文背书。任何丢点、额外字段、自由文本覆盖范围、量词切换、旧审计不匹配、截断或最终仍超限都整批拒绝，不重试、不截断正文、不提高上限。

展示字数沿用发布布局的同一计量函数。没有范围表达式或旧运行没有新开关时，保留旧压缩路径。新开关由服务端设置且不可修改，保持旧未知请求和研究记录身份。模型调用节点和 2,000 输出 Token 上限不增加。
