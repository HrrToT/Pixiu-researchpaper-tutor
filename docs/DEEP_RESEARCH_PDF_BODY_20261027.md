# 完整 PDF 正文、物理页与结构保留

针对 GROBID 将引言开头和总结连接、中间正文缺失的问题，`parse_tei_xml(..., pdf_path)` 现在用独立 PDF 页文本构建正文。TEI 元数据、实际印刷标题、结构化表格及公式仍保留。本轮没有追加 DeepSeek 案例，也没有重建生产索引。

## 实现与边界

`core/pdf_source_sections.py` 按物理页保留全部可提取文本，绝不跨页拼接。只用页上实际匹配到的完整标题行或最多三行标题标注章节；GROBID 的页提示用于约束匹配，后续页在遇到新标题前延续原章节。不使用不在 PDF 上的标题，也不把正文全部改成 Page N。

生成的页内区段具有独立 ID、页码、文本偏移及正文提取版本。索引保留 `text_source=pdf_page_text` 和 `body_extraction_version=1`。这些标记不授予表格单元格验证，原结构化表格及其几何校验数据保持独立。公式继续作为 `grobid_formula` 补充片段，不继承跨页章节的第一页作为猜测的公式页。

没有可提取 PDF 文本时明确拒绝规范正文入库，不静默重用已知可能残缺的 TEI。无 PDF 参数的 TEI 单独解析接口保持原行为。原始 PDF、已有任务、旧研究来源快照均不改写；索引内容变化自然形成新版本。
