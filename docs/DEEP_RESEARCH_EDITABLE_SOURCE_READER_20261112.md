# 单条可编辑解释直接从原文组织（.423）

多次AD1N开发案例存在两条目标：技术解释可编辑，边界内容受保护。旧“单目标从原文解释”仅在整份回答只有一条时触发；这类常见的两目标结构仍把完整技术草稿作为unverifiedPointHint发给改写器，改写常原样保留术语和公式。该观察不是对所有可读性问题的完整因果证明。

新任务增加服务器固定、创建后不可变的 `audienceEditableSourceContractVersion=1`。仅在现有契约9、保护内容编辑预算已经启用、保护目标非空且可编辑目标恰好一条时，内部对该可编辑子集启用既有source-first准备方式：发送固定问题、本目标原引用和要求，不发送该段完整技术草稿提示。模型仍只能返回本条ID，不能编辑受保护目标。

完整父报告的来源校验仍在子集准备前执行，未绕过受保护目标的来源有效性检查。保护内容作为明确未核验的上下文供识别分工，不能当成论文证据或借用其引用；服务器按原对象合并。多条可编辑目标保留既有职责提示，整份单目标继续既有路径，不迁移旧任务或改变旧pending/received请求。

新模式进入输入摘要和保存状态。已有原文、上下文、问题、目标种类、引用权限、保护对象、发布字数预算、3072输出Token与24KB输入上限保持；同一已收到回复可复用，不能切换模式重发。后续事实、数值、条件、范围和完整性核查不变。本改动不重新分类原主张或授予事实认可。
