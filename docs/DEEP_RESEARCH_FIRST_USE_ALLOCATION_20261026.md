# 元信息25：主动选择首次使用前创建

## 问题与实现

E1-v78把全局步骤编号填入帧内createInScope编号，transformed_3dgs和additional_3dgs的创建晚于首次更新，产生before_creation与cycle。数字坐标仍保留原含义；新版本只增加明确选择`before_first_use`，不自动修复旧数字。

选择该模式时，由提案已经声明的state读取/updates确定首次步骤使用。per_frame资源在那个帧内步骤前创建；per_repeat资源若首次用于帧块，在进入整个帧块前创建；若首次用于循环外步骤，则在该步骤前创建。只计算生命周期边界，不填写初始化数据、模型参数或操作。初始化依赖仍由原检查验证；仅在其他组件初始化中使用的资源没有可推导的步骤使用，须显式选择坐标。

找不到使用、作用域无效或per_frame资源首次出现在循环外时拒绝，不选择默认位置。原组别、依赖、预算、初始化与科学检查保持。逐帧临时结果不能直接被循环外per_repeat步骤读取；提示明确帧内保存及后续分析中的配对汇总，不通过放宽scope检查解决。
