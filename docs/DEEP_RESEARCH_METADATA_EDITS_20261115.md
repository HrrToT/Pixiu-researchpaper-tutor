## 已实现的行为

首次实现使用不可变服务器标记 `workflowMetadataEditsContractVersion1`，`.466` 新运行使用版本2；旧版本1的提示和请求身份保留。只有完整反馈全部属于可定位的跨组读取错误时使用编辑模式，支持删除或替换冻结范围内的完整读取项。其他错误仍保留原有的一次全文修订能力；编辑失败后不再追加全文修订，也不增加模型调用预算。

请求包括完整原始问题、实验规划、全部原文证据、原稿及直接可读的错误反馈。模型必须回显原稿摘要，返回明确编辑和未解决问题；服务器不推断删除项、不补科学参数、不自动纠正引用。原稿摘要、编辑范围和实际 schema 均进入请求身份，范围单独持久化并校验。

编辑以原稿数组索引解释，所有目标先验证再按原始索引倒序应用，防止删除导致后续目标移位。拒绝错误摘要、越权、重复、空编辑、无变化替换、未知操作、错误读取类型及未解决问题。无法支持的字段类型不能通过编辑模式悄悄删除。

原始模型响应、编译后的 wire 和最终解码值分别保存并各有摘要。编译后仍执行全部来源、分组、生命周期和容量检查，随后继续原有科学审核。缓存和 SQLite 重开会重新验证相同编辑与编译结果，不触发第二次模型调用。对原稿、编辑范围、原始响应或编译结果的篡改会被拒绝。

编辑模式使用独立的原生 JSON schema，内部模式标记不发送为 Provider 参数。输入限额与 Token 预留按该请求的实际 schema 开销计算。输出仍限 6144、请求时限90秒、修订输入40KB；整轮18次调用、10万Token、6分钟预算不变。旧运行不能事后启用该模式，初次规划与其他节点的请求保持原样。
