# 保留范围条目的修订角色

`.325` 真实验证暴露：生成阶段已编译为范围表达式的 c2，可以在修订时返回 scopeExpression=null 的普通文字，绕过结构化范围专项审查。“未验证范围：其他场景或感知质量”因此获得机器接受，但不能计为安全的证据边界表达。

`.326` 对新建 claimCheckContractVersion=5 的核查任务，将原生成范围审计中已有条目的身份带入修订请求。每一批只包含本批目标的必要身份，不将旧范围审计当作语义批准。指定条目必须返回非空 scopeExpression 对象、空正文和空条件，继续由既有编译器生成文字并送独立范围审核。缺失、null 或普通文字降级返回按 scope_role_downgrade 拒绝，错误审计与已结算回复保持；不重发。无法支持修订时可省略该修订，不可绕过专项核查来制造成功。

修订缓存身份包含必要范围条目集合，集合变化不能复用旧回复。旧版本 1—4 保持原行为；普通事实条目不强制范围结构。有效范围编译后仍 unchecked，没有继承旧核查状态，原字数、证据权限、数值与最终完整性门槛保持。

使用 `.325` 已结算原始修订回复直接回放：旧接收器接受普通文字 c2，新接收器拒绝该条并明确记录 scope_role_downgrade；没有模型调用和生产写入。该回放仅证明接收器行为，不证明新模型能按要求输出。40 项初步定向测试通过；加入真实图节点传递身份的覆盖后，最终固定源码的 60 文件、1,044 项关联回归通过（pytest 89.88 秒、外部 93.125 秒），无模型调用。证据：deep-research-evidence/scope-role-326-actual-receiver-replay-20261029.json、scope-role-326-final-regression-20261029.json。
