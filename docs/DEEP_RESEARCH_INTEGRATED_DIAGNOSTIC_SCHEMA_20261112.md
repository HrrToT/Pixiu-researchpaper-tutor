# 审核主字段清单包含诊断绑定（.426）

AD1N-v15的核心解释审核返回claimId、reason、scopeAudit，却遗漏必需的diagnosticFacts。现有主审核清单只列出前三项，追加的诊断说明才要求第四项。这个不一致是可修正的遗漏风险，不能据此断定模型缺字段的唯一原因。

新任务将不可变 `reviewDiagnosticContractVersion` 从1设为2。完整事实单判定路径的主响应清单直接列出diagnosticFacts，并明确支持与不支持两种判定均需该数组，没有新增来源事实时必须明确返回空数组。诊断绑定的原始字段、来源权限、数值与作用域检查不变；服务不补空数组、不再次生成、不把遗漏字段当通过。

版本1及没有该规则的旧任务保持原提示和判定。独立的建议审核及其他不符合条件的路径不启用新主清单。既有分区观察通过同一事实审核器，算子推理仍使用原有独立协议；本改动没有合并不同判定路径或扩大认可范围。
