# 元信息23：状态与阶段输出的引用反馈

## 实际问题

E1-v77在对照组观察中，把两组渲染输出armA_rendering/armB_rendering当成持久state读取。原生成和唯一修正规范值相同。旧反馈虽然定位到准确路径，却在说明中使用内部phaseId语法，与模型必须填写的stepIndex/outputStage语法不一致；还没有说明两个输出分别属于哪个组。

简单改成阶段输出引用也不够：实验组输出不属于对照组。模型必须重新组织组内测量与之后的配对分析，程序不能自动改名或加入组件来规避检查。

## 新版本行为

保持22的原格式、解码及科学检查。只对metadata.read.unknown_state补充由当前提案明确声明的生产者：stepIndex、outputStage、outputId、groups、scope，以及not_earlier/groups/scope/invalid_groups等结构阻碍。保留所有同名生产者，包括不兼容及未来生产者；没有匹配时为空，不猜测、不选择替代项。候选只说明所声明的数据流，不是来源证据、可执行性或科学认可。

反馈中的expected改为模型实际填写的stepIndex/outputStage/outputId/selector。生成和修正提示共同区分持久组件与计算结果、组内观察与分析中的配对比较。精简重复说明保留所有材料、提案、诊断与预算。
