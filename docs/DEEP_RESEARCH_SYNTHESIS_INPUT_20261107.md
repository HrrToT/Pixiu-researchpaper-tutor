# 事实研究的起草输入整理（.404）

G1N-v9 的原始失败保留：PGSR 的 TSDF 段落已读取并提取，但没有进入起草候选；固定提示约 15.5KB，最终仅有 12 条证据进入原 24KB 输入窗口。缺少起草输入不能解释成论文缺少方法，也不能直接在旧回答中补入已知答案。

本次新任务由服务器冻结 `synthesisInputContractVersion=1`，仅配合 factualPrompt3、互斥 body1、scope5 的事实核对/论文比较启用。旧任务缺少此字段、旧 factualPrompt1/2、实验和方向综述保持原路径。

## 起草规则合并

| 原约束 | 新输入位置与保留方式 |
| --- | --- |
| 用户原话、每个完成标准、全部来源限制 | 原问题逐字保留；完整义务使用既有可逆 JSON 表示，运行时检查往返一致；来源目录保持 |
| 字段、互斥正文/边界、长度 | 原 body1 指导原样保留；最大结论数、完整编译文本长度、独立审核保持 |
| 逐断言自有引用、来源归属、跨论文推理 | 合并在 CORE；比较表中的其他方法不是被比较论文自报，硬件不能跨来源拼接 |
| 数值、行/组/变体/指标/单位/表注 | 原 table_input_contract 指导保持一份；CORE 保留表注、代码与测量、主表与消融/剖析的区别 |
| 算术、整系统比较、受控方法效应 | CORE 分别说明；未知条件不推成已知差异、计算不可能或完全不可比 |
| 缺席、有限证据、必要条件、全称结论 | CORE 合并重复限制；原 scope5、数值边界与独立语义核验继续执行 |
| 科学术语、未核验起草前提、发布版本 | 原术语常量、draftingBasis 类型、条件启用的 publicationIdentity 指导保持 |
| 阅读建议、访问披露、保存范围、模板 | 合并到 CORE，结果正文仍简洁，取得全文片段不等于通读论文或用户已读 |
| 目标/观测/保证、流程解释、其他动态规则 | 图中原条件与常量继续添加；不把禁用能力静默视为启用 |

事实、数值、归属、范围、整答完整性审核器没有修改；调用、Token、时间和 24KB 输入限制没有增加。

## 流程段落导航

既有请求角色导航在新输入协议下，额外匹配用户明确请求的操作对象，如网格、点云、深度图、法线图、特征。只在该引文自己的句子中匹配动作与对象，不借另一段落/标题提供动作，不使用论文名、目标数值或参考答案。

来源/版本/义务资格、literal 核对、短小片段质量规则、20 候选上限与原证据容量分配器保持。无法识别对象时维持既有分数；这只是导航，不把相关性或科学支持判为通过。实际阅读顺序与阅读上限不变。
