| 结果简洁性 | 组合输出保留用户要求的各步简短结论、句子去重、显式字数优先；完整原文/引用保留在一份成果；43项离线回放通过 |
| 研究确认连续性 | 计划修改保留到刷新；报告预览可返回；状态读取失败留在对应研究，查询不重新执行模型 |

| 可访问性 | 处理记录对话框焦点限制、Escape关闭、返回触发按钮；回归通过 |
| 论文概览 | 解析/生成状态留在阅读区；已有概览提供明确查看入口，不自动切换正文 |

## 查找入口的边界

- 搜索范围为当前任务；跨任务先切换任务。
- 学习记录只打开实际保留的问题、作答和反馈，不重新生成。
- 已删除、从未保存或服务端不可读取且无本地备份的数据不能保证恢复。
- 服务不可用时，处理记录明确提示列表可能不完整；已有论文、对话、成果和学习记录仍保留入口。
